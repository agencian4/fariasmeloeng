# Farias de Melo Engenharia — Site

Site institucional (proposta Agência N4) para a Farias de Melo Engenharia — eng. civil João Melo.

## Estrutura
- `index.html` — site (HTML/CSS/JS em arquivo único)
- `img/` — fotos de obra (origem: Instagram @fariasdemeloeng)
- `marca/` — página da proposta de nova marca (comparativo com a atual)

## Publicar no GitHub Pages
1. Suba o conteúdo desta pasta na raiz do repositório.
2. Settings → Pages → Branch `main` / pasta `/ (root)`.
3. O site fica em `https://<usuario>.github.io/<repositorio>/` e a proposta de marca em `/marca/`.

Dependências via CDN: GSAP 3.12.5 + ScrollTrigger, Lenis 1.1.13, Google Fonts (Archivo, IBM Plex Mono).
